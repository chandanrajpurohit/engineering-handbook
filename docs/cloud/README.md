# Cloud Documentation

This section contains documentation, architectural guides, and best practices for **Cloud** technologies.

## Technologies Covered

- **[Amazon Web Services (AWS)](./aws/README.md)** - Comprehensive cloud computing platform provided by Amazon.
- **[Microsoft Azure](./azure/README.md)** - Microsoft cloud computing service for application management via Microsoft-managed data centers.
- **[Google Cloud Platform (GCP)](./gcp/README.md)** - Suite of cloud computing services that runs on the same infrastructure that Google uses internally.
