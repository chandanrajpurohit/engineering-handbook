# Ai Documentation

This section contains documentation, architectural guides, and best practices for **Ai** technologies.

## Technologies Covered

- **[LangChain](./langchain/README.md)** - Framework designed to simplify the creation of applications using large language models (LLMs).
- **[LangGraph](./langgraph/README.md)** - Library for building stateful, multi-actor applications with LLMs, used to create agent and multi-agent workflows.
