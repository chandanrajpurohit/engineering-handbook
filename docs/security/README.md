# Security Documentation

This section contains documentation, architectural guides, and best practices for **Security** technologies.

## Technologies Covered

- **[Keycloak](./keycloak/README.md)** - Open Source Identity and Access Management for modern applications and services.
- **[OpenID Connect (OIDC)](./oidc/README.md)** - Simple identity layer on top of the OAuth 2.0 protocol.
- **[JSON Web Tokens (JWT)](./jwt/README.md)** - Proposed Internet standard for creating data with optional signature and/or encryption whose payload holds JSON.
