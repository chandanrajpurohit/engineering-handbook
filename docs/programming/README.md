# Programming Documentation

This section contains documentation, architectural guides, and best practices for **Programming** technologies.

## Technologies Covered

- **[Python](./python/README.md)** - High-level, general-purpose programming language with dynamic semantics and rich ecosystem.
- **[Java](./java/README.md)** - Class-based, object-oriented programming language designed for portability and enterprise scale.
- **[JavaScript / TypeScript](./javascript/README.md)** - Lightweight, interpreted, or just-in-time compiled programming language with first-class functions for the web and servers.
