# Observability & Monitoring Documentation

This section contains documentation, architectural guides, and best practices for **Observability & Monitoring** technologies.

## Technologies Covered

- **[Prometheus](./prometheus/README.md)** - Open-source systems monitoring and alerting toolkit.
- **[Grafana](./grafana/README.md)** - Multi-platform open source analytics and interactive visualization web application.
- **[Grafana Loki](./loki/README.md)** - Horizontally-scalable, highly-available, multi-tenant log aggregation system inspired by Prometheus.
- **[AppDynamics (Cisco / Splunk)](./appdynamics/README.md)** - Enterprise application performance monitoring (APM) and full-stack observability platform.
