# Data Engineering Documentation

This section contains documentation, architectural guides, and best practices for **Data Engineering** technologies.

## Technologies Covered

- **[Apache Airflow](./airflow/README.md)** - Open-source workflow management platform for data engineering pipelines (DAGs).
- **[Apache Spark](./spark/README.md)** - Multi-language unified analytics engine for large-scale data processing.
- **[Apache Flink](./flink/README.md)** - Framework and distributed processing engine for stateful computations over unbounded and bounded data streams.
